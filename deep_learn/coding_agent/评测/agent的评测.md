# 你是怎么做 Aider Polyglot 测评的？

使用的是 Harbor 评测框架，接入了 Aider Polyglot 的完整 225 道任务。每道题都在独立容器环境里运行，Agent 根据题目要求实际读取和修改代码，最后由独立测试程序判分，而不是根据模型自述判断成功。这次使用的是 `gpt-5.6-luna`，推理强度设为 high，单题最多 120 个工具轮次，四个任务并发执行。同时启用了测试反馈修复：首次测试失败后，把错误输出交回同一个 Session，再给一次修复和复验机会。运行过程中，我把环境、网络和超时异常与代码测试失败分开记录，避免把它们混成一个失败率。

# 最终结果怎么样？

这次共完成了 225 道任务，其中 221 道拿到了明确判分，213 道通过、8 道未通过，另外 4 道没有获得明确判分。因此，有效判分任务的通过率是 **96.38%**；把全部 225 道任务，端到端通过率是 **94.67%**。这里我会特别说明，这个结果包含测试反馈后的修复，并不是第一次生成代码的通过率。另外，它代表特定模型和配置下，FirstCoder 整套系统的本地评测表现，不是 Aider 官方排行榜成绩，也不能直接证明某个模块单独提升了多少效果。

# 介绍一下 Aider Polyglot 这个 benchmark。

我把 Aider Polyglot 理解成一个多语言代码编辑评测集。它包含 225 道来自 Exercism 的编程练习，覆盖 Python、JavaScript、Java、Go、Rust 和 C++ 六种语言。它不是只让模型输出一段看起来正确的代码，而是要求根据需求修改已有文件，并通过真实测试。因此，它能检验需求理解、代码修改、接口兼容和边界处理等能力。我选择它，是因为它有明确、自动化的验收标准，也能覆盖多种语言；但它主要还是编程练习，不能完全代表大型项目里的长期开发和复杂协作。

# 介绍一下Harbor评测框架。
 
 Harbor 是一个自动组织 Agent 考试的框架。它本身不是题库，也不是负责解题的 Agent，而是把任务、运行环境、Agent 和判分程序串起来：先加载任务，在隔离容器里准备代码和依赖，再启动 Agent 完成操作，最后运行任务提供的验证程序，并保存分数、日志、耗时和异常，方便复现和排查问题。[Harbor 官方文档](https://www.harborframework.com/docs) 在我的 FirstCoder 测评里，Aider Polyglot 相当于题库，FirstCoder 是考生，Harbor 负责组织考试，验证程序负责判卷。我通过适配器让 Harbor 能在任务环境里启动 FirstCoder。这样就不用为每套题重复开发环境管理和结果收集流程，而且评估的是 Agent 实际完成任务的能力，不只是模型回答得像不像正确答案。

按照官网的定位，Harbor 是一个**在容器化环境中评估和优化 Agent 与模型的框架**，由 Terminal-Bench 团队开发。它不是某一套具体题库，而是承载不同评测任务的统一运行框架。它通过标准化接口，把任务、Agent 和执行环境连接起来：一个任务通常包含需求说明、容器环境和验证脚本，Agent 在环境里实际完成操作，再由验证程序产生评分。它既支持已有的主流 Agent，也允许接入自研 Agent，并提供基准数据集注册表和云端沙箱集成，方便规模化运行。除了评测，Harbor 也面向提示词优化、训练轨迹生成和强化学习等场景。所以我会把它概括为：**一套用于组织、执行和扩展 Agent 评测与优化流程的基础设施。**

# Harbor 和 Aider Polyglot、Terminal-Bench 分别是什么关系？
我会把它们区分为“评测框架”和“评测题库”。**Harbor 负责怎么测，Aider Polyglot 和 Terminal-Bench 决定测什么。** Harbor 管理任务环境、启动 Agent、调用验证程序并收集结果；Aider Polyglot 主要考察六种编程语言下的代码编辑和测试通过能力；Terminal-Bench 则更侧重终端环境里的多步骤任务，比如编译软件、配置服务和排查环境问题。它们不是同一个东西，也不是三个并列的框架。更具体地说，Harbor 是 Terminal-Bench 2.0 的官方运行框架；而在我的项目中，是通过 Harbor 适配后的 Aider Polyglot 任务来评测 FirstCoder，并不是直接使用 Aider 自身的 Agent。因此，即使使用相同题库，本地成绩也不能直接视为 Aider 官方榜单成绩。[Harbor 官方说明](https://www.harborframework.com/docs/tutorials/running-terminal-bench)、[Aider Polyglot 介绍](https://aider.chat/2024/12/21/polyglot.html)
