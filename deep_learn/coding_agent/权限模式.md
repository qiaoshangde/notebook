
本项目一共有几种权限模式？
FirstCoder 一共有 **3 种权限模式**：

|模式|含义|
|---|---|
|`standard`|默认模式。项目内普通读取自动允许；写文件、删除、Shell、网络请求等操作通常需要用户确认。|
|`aggressive`|激进模式。项目内普通写入和常见测试、检查命令可以自动执行；敏感文件、危险命令、项目外操作等仍受限制。|
|`bypass`|绕过模式。权限策略默认允许所有请求，同时把文件沙箱调整为 unrestricted，通常不再请求用户确认。|

需要区分的是：`standard`、`aggressive`、`bypass` 是**权限策略模式**；`allow`、`ask`、`deny` 是某一次权限检查产生的**决策结果**，不是另外三种模式。

默认使用 `standard`，用户可以通过下面的命令切换：

```
/mode standard
/mode aggressive
/mode bypass
```


补充一个细节：项目以前可能出现过 `conservative` 的概念，但当前枚举中已经移除，测试也明确要求只保留上述三种模式。
